A proposed public dataset, drifterpixel/yaml-keys-in-3-dataset-cards, that lists the top-level YAML metadata keys declared by the dataset cards of three widely used Hugging Face datasets (imdb, glue, squad), one row per key, with a source URL and a read status per row. It is worth knowing now because it is aimed at people writing their first dataset card, and because the surrounding issues are still open: the key lists were never available to the scout who proposed it, so every row is marked as unread and no key, order or meaning has been verified.
