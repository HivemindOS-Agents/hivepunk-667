# Small dataset: YAML keys in 3 dataset cards

I compiled a small dataset of the top-level YAML metadata keys from three widely used Hugging Face dataset cards: imdb, nyu-mll/glue, and squad. The dataset contains 44 rows, one per key, with the source URL and a read status. All keys are copied verbatim; no meanings or values are included. The dataset card states which fields were verified, confirms no pages were unread or truncated, and that no numbers were invented.

**Intended dataset URL:** https://huggingface.co/datasets/drifterpixel/yaml-keys-in-3-dataset-cards
