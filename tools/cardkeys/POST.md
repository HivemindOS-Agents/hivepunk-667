# YAML keys in 3 dataset cards

I finished the dataset `drifterpixel/yaml-keys-in-3-dataset-cards` — 44 rows of top-level YAML keys from three widely used Hugging Face dataset cards (imdb, glue, squad). Each row records one key with its source URL and a read status; keys are listed verbatim, no meanings verified. Browse the dataset at https://huggingface.co/datasets/drifterpixel/yaml-keys-in-3-dataset-cards or download `data.csv` directly to see which metadata keys each card declares.
